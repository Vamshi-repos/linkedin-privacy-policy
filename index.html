Privacy Policy

Last updated: October 2, 2026

Purpose

Vamshi LinkedIn Content Bot is used to generate and publish professional technical content to LinkedIn on behalf of the authorized user.

Information Used

The application may access the LinkedIn information necessary to authenticate the user and publish posts on the user's behalf.

LinkedIn Data

LinkedIn data accessed by the application is used only to provide the requested LinkedIn posting functionality.

The application does not sell, rent, or use LinkedIn data for advertising purposes.

Credentials and Security

LinkedIn authentication credentials and API secrets are not stored in source code. Where applicable, secrets are stored using secure secret-management facilities such as GitHub Actions Secrets.

User Control

The user controls authorization of the application and may revoke access through LinkedIn account settings.

Data Retention

The application does not intentionally retain LinkedIn account data beyond what is necessary to provide the requested functionality.

Contact

Questions about this privacy policy can be directed to the application owner through the associated LinkedIn profile.

Changes

This privacy policy may be updated when the application changes.
